Стек SecondBrain

Один список всего, что выбрано, и почему. Подробные причины в заметках docs/decisions, номер заметки указан у каждой части. Версии указаны по состоянию на 2026-11-17.

Общее ограничение. Всё из списка бесплатное, своего сервера нет.

1. Язык. TypeScript.
Почему. Модель данных строгая, и типы ловят ошибки в записях, времени и связях ещё при сборке. Идёт в шаблоне Vite.
Заметка 1.

2. Интерфейс. React 19.
Почему. Самая большая экосистема, много готовых ответов для новичков, нейросетевые помощники лучше всего пишут именно React.
Заметка 1.

3. Сборка и разработка. Vite 8.
Почему. Быстрый запуск и сборка, готовый шаблон для React и TypeScript, к нему подключается установка как приложение.
Заметка 1.

4. Установка и работа без интернета. Веб-приложение (PWA) через vite-plugin-pwa.
Почему. Ставится из браузера на телефон и компьютер, кэширует себя и работает без сети. Одна кодовая база.
Заметка 2.

5. Установочный файл Android. Capacitor.
Почему. Оборачивает то же веб-приложение, не зависит от фреймворка. Нужно будет отдельно решить вход через Google внутри такого файла.
Заметка 2.

6. Хранилище в браузере. IndexedDB через Dexie 4 и dexie-react-hooks.
Почему. На 10 000 записей все нужные операции укладываются в доли миллисекунды, поиск по тексту около 0,1 секунды. Не нужен wasm и отдельный поток. Живые запросы для React готовы.
Заметка 3.

7. Вход через Google и Диск. Google Identity Services и Google Drive API v3, доступ drive.appdata.
Почему. Приложение видит только свою скрытую папку на Диске пользователя, остальной Диск ему недоступен. Не нужен свой сервер. Проверено на мини-приложении: вход, запись, чтение, обновление.
Заметка 4.

8. Шифрование. Web Crypto, шифр AES-GCM 256, ключ из пароля через PBKDF2 с SHA-256 и 200 000 кругов.
Почему. Встроено в браузер, сторонние библиотеки не нужны. Диск видит только шифр, ключ у пользователя. Проверено на мини-приложении.
Заметка 5.

9. Время события. Период from и to в строках одной длины, без часового пояса.
Почему. Точное и приблизительное время хранится одинаково, порядок в ленте получается обычной сортировкой.
Заметка 6.

10. Помощник. Запросы к нейросети по ключу пользователя, конкретные модели не зафиксированы.
Почему. Не нужен свой сервер и оплата, пользователь сам решает, включать ли помощника. Приложение работает полностью и без него.
Заметка 7.

11. Лицензия. AGPL-3.0.
Почему. Продукт про приватность, чужие версии на нашем коде тоже должны оставаться открытыми. React и Vite под MIT, Dexie под Apache-2.0, они совместимы с AGPL-3.0. Лицензии остальных библиотек проверяем перед подключением.
Заметка 8.

12. Хостинг. GitHub Pages.
Почему. Бесплатно, рядом с кодом, работает по https. Нужны только статические файлы. Проверено на тестовой странице: установка, офлайн, уведомления.
Заметка 9.

13. Проверки. Vitest для логики, проверка типов, линтер oxlint, форматирование Prettier, всё одной командой npm run check, плюс ручная проверка на телефонах.
Почему. Ошибки чаще всего в логике времени и слияния, её проще всего проверять небольшими тестами. Интерфейс проверяем руками.
Заметка 10.

14. Репозиторий и управление проектом. GitHub для кода, YouGile для задач.
Почему. Код и лицензия живут в одном месте, задачи ведутся на доске с лимитами колонок.

Что пока не проверено
1. Телефоны Apple, устройства нет.
2. Вход через Google внутри установочного файла Android.
3. Скорость хранилища на телефоне и поиск записей человека через связи.
4. Обновление токена Google после его истечения.
