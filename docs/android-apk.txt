Установочный файл для Android (APK)

Дата записи. 2026-11-19.
Карточка SB-41. Опирается на решение 2 (платформа) и решение 1 (стек).

Что это

Готовое веб-приложение, упакованное в оболочку Android через Capacitor. Код приложения не переписывался. Собранные файлы (папка dist) лежат внутри APK, поэтому приложение открывается и без интернета, а данные хранятся в базе внутри приложения, как в браузере. Внутри оболочка открывает приложение по адресу https://localhost, это безопасный контекст, шифрование и хранилище работают.

Параметры

1. Идентификатор приложения app.secondbrain.notes. Менять после выпуска нельзя, на нём держится вход Google для Android.
2. Название SecondBrain, значок кольцо на синем фоне, как у приложения в браузере (адаптивный значок Android, исходники в resources).
3. Минимальный Android 7.0 (24), целевой 16 (36). Размер около 4 МБ.
4. Подпись пока отладочная (debug), файл устанавливается на телефон вручную. Для магазина понадобится настоящий ключ, пока не нужен.

Как собрать

1. Нужны Node, Java 21 (подходит Eclipse Temurin 21) и Android SDK (платформа 36, build-tools 34).
2. В папке SecondBrain выполнить npm run android:sync (собирает веб-часть и копирует её в android).
3. В папке android выполнить gradlew assembleDebug. Готовый файл: android/app/build/outputs/apk/debug/app-debug.apk.
4. Если сеть идёт через локальный прокси, Gradle его сам не видит. Надо передать -Dhttp.proxyHost, -Dhttp.proxyPort, -Dhttps.proxyHost, -Dhttps.proxyPort. Загрузки при этом иногда обрываются на рукопожатии, повторный запуск продолжает с места обрыва (скачанное хранится в кэше). У меня сборка прошла с третьей попытки.

Что проверено мной

1. Файл собирается. Идентификатор, название, минимальный и целевой Android, разрешение только на интернет, адаптивный значок, веб-часть внутри файла (index.html, скрипты, стили, manifest, sw.js).
2. Все проверки приложения (614) проходят, сборка веб-части проходит.
3. В установленном приложении окно входа Google не открывается (Google запрещает вход во встроенном окне), вместо него показывается понятное объяснение. Есть проверка, при намеренной поломке она падает.

Чего я не мог проверить

На устройстве я ничего не запускал: ни телефона, ни эмулятора у меня нет. Установка, значок на экране, работа без интернета, поведение кнопки «назад» и подключение Диска в самом приложении проверяет пользователь на телефоне. Порядок ниже.

Проверка на телефоне

1. Скопировать app-debug.apk на телефон, разрешить установку из этого источника, установить.
2. Значок SecondBrain появился, при нажатии открывается приложение на быстрой записи.
3. Записать мысль, закрыть приложение полностью, открыть снова. Запись на месте.
4. Включить режим «в самолёте», записать мысль, посмотреть ленту. Всё работает.
5. Кнопка «назад»: из карточки записи ведёт в ленту, из ленты закрывает приложение, а не показывает пустой экран.
6. Верхняя и нижняя части экрана: ничего не закрыто строкой состояния и нижней панелью телефона.
7. Настройки, «Подключить Google Диск»: должно появиться объяснение, что вход в приложении пока не готов.
8. Копия данных: «Сохранить копию» и «Загрузить из файла» работают (проверить, что файл сохраняется в загрузки телефона).

Вход Google в APK: что нужно сделать

Решение 2 заранее отметило риск: Google не разрешает вход во встроенных окнах. Что нужно, чтобы Диск подключался и в APK.
1. В Google Cloud создать второго клиента типа Android с идентификатором приложения app.secondbrain.notes и отпечатком SHA-1 ключа подписи. Отпечаток отладочного ключа этого компьютера: 1B:30:C0:80:51:DB:63:B1:A2:84:31:93:58:B8:1C:CF:6E:F4:7D:6D. Для настоящей подписи нужен отпечаток настоящего ключа.
2. В приложении открывать вход в системном браузере (Chrome Custom Tabs) с кодом подтверждения (PKCE), возвращаться по ссылке приложения app.secondbrain.notes и менять код на токен. Появится и долгоживущий токен обновления, который заодно решит вопрос тихого входа после закрытия приложения.
3. Токен обновления придётся хранить на устройстве. Он даёт доступ только к скрытой папке приложения на Диске, а файлы в ней зашифрованы. Это нужно записать отдельным решением до реализации.
Пока вместо этого показывается объяснение, а данные между устройствами можно переносить файлом копии.

Что не сделано

1. Вход Google в APK (см. выше).
2. Настоящая подпись и выпуск в магазин.
3. Проверка на телефоне (делает пользователь).
4. Проверка на старых версиях Android (7 и 8). Минимальная версия указана по умолчанию Capacitor.
