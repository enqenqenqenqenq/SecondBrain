Решение 9. Хостинг

Статус. Принято.
Дата записи. 2026-11-17.

Контекст
Приложению нужна ссылка по https, чтобы его можно было открыть и установить с телефона. Своего сервера нет, платить нечем.

Варианты
1. GitHub Pages. Бесплатно, уже есть репозиторий.
2. Netlify, Cloudflare Pages, Vercel. Тоже бесплатно, но нужен ещё один аккаунт и ещё одно место, где настраивается публикация.
3. Собственный сервер. Противоречит ограничению «без своего сервера».

Выбор
GitHub Pages.

Причины
1. Бесплатно и рядом с кодом.
2. Работает по https, это нужно для установки приложения, уведомлений и входа через Google.
3. Приложению нужны только статические файлы, больше ничего.

Что проверено
На тестовой странице: установка на Android, работа без интернета и уведомления.

Последствия
1. Адрес вида имя.github.io/название-репозитория, у Vite нужно задать базовый путь. Все пути в приложении должны быть относительными.
2. Этот адрес надо добавить в разрешённые источники JavaScript у входа через Google.
3. Свои заголовки сервера на Pages задать нельзя. Нашему приложению они не нужны.
