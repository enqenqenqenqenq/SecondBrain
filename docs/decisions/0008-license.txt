Решение 8. Лицензия проекта

Статус. Принято.
Дата записи. 2026-11-17.

Контекст
Репозиторий публичный. Нужна лицензия, иначе по закону код нельзя использовать.

Варианты
1. AGPL-3.0.
2. MIT. Проще, без требований открытости.
3. Apache-2.0. Добавляет защиту по патентам.
4. Без лицензии.

Выбор
AGPL-3.0. Текст в файле LICENSE.

Причины
1. Продукт про приватность и контроль данных. Любая чужая версия на нашем коде, в том числе работающая как сетевой сервис, тоже должна оставаться открытой.
2. Основные библиотеки проекта, React и Vite под лицензией MIT, Dexie под Apache-2.0, можно использовать в проекте под AGPL-3.0.

Последствия
Часть разработчиков не захочет брать такой код. Для учебного проекта это приемлемо.
