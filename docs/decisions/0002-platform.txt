Решение 2. Платформа: веб-приложение с установкой на телефон

Статус. Принято.
Дата записи. 2026-11-17.

Контекст
Приложение нужно и на телефоне, и на компьютере. Сервера у нас нет и не будет. Хотим одну кодовую базу.

Варианты
1. Веб-приложение, которое ставится на экран телефона (PWA). Для Android позже установочный файл через Capacitor.
2. Отдельные нативные приложения для Android и iPhone. Две кодовые базы, для новичков слишком много.
3. Кроссплатформенные каркасы (Flutter, React Native). Нужно изучать новый стек, а веб-версия на компьютере всё равно понадобится.

Выбор
PWA на выбранном стеке. Установочный файл для Android собираем через Capacitor.

Причины
1. Одна кодовая база для телефона и компьютера.
2. Ставится из браузера без магазинов приложений.
3. Работает без интернета и хранит данные на устройстве.

Что проверено
На Redmi 10C, Android 13, Chrome 156: установка как приложение, работа без интернета, уведомления работают.
На iPhone не проверено, устройства нет. По документации там нет фоновой работы, а уведомления есть только у установленного приложения. Поэтому для iPhone обещаем только установку и работу без интернета.

Последствия
1. Напоминания в фоне надёжно работают только на Android.
2. В установочном файле через Capacitor вход через Google внутри встроенного окна запрещён правилами Google. Для APK понадобится вход через системный браузер или готовый плагин входа. Проверить до начала работы над APK.
