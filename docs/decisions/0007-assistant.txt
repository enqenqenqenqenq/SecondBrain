Решение 7. Помощник на нейросети: необязательный, по собственному ключу

Статус. Принято.
Дата записи. 2026-11-17.

Контекст
Нейросеть может помогать искать записи по смыслу и предлагать связи между людьми и записями. Но у проекта нет сервера и денег на оплату чужих запросов, а данные пользователя не должны уходить без его ведома.

Варианты
1. Собственный сервис с платной подпиской. Нужны сервер и деньги.
2. Только локальная модель на устройстве. Тяжело для телефона.
3. Помощник по ключу, который пользователь подключает сам.

Выбор
Помощник по собственному ключу пользователя. Без ключа приложение работает полностью, как обычно.

Причины
1. Не нужен свой сервер и оплата.
2. Пользователь сам решает, включать ли помощника и что отправлять.
3. Конкретные модели в проекте не называются, нужен только ключ.

Правила
1. Включение по желанию, отключение удаляет ключ.
2. Ключ хранится только на устройстве, не уходит ни на Диск, ни в файл выгрузки.
3. Каждое предложение помощника подтверждает пользователь.

Последствия
Помощник идёт после основной версии, приоритет «если успеем». Никакая основная функция от него не зависит.
