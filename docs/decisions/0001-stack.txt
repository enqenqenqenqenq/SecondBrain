Решение 1. Технология приложения

Статус. Принято.
Дата записи. 2026-11-17.

Контекст
Нужно выбрать технологию для интерфейса. Команда учебная, опыта мало. Приложение должно ставиться на телефон, работать без интернета и хранить данные на устройстве.

Варианты
1. React с TypeScript и Vite.
2. Svelte. Проще и легче, но меньше готовых библиотек и ответов в интернете.
3. Vue. Что-то среднее, особых причин брать нет.

Выбор
React, TypeScript и Vite.

Причины
1. У React самая большая экосистема, на любой вопрос новичка уже есть ответ.
2. Нейросетевые помощники лучше всего пишут именно React.
3. Всё нужное подключается готовым: установка и работа без интернета через vite-plugin-pwa, база в браузере через Dexie, шифрование через встроенный Web Crypto.
4. Android-приложение собирается через Capacitor, он не зависит от фреймворка.
5. Навык пригодится дальше.

Последствия
Больше шаблонного кода и правил, чем в Svelte, в первую очередь хуки и зависимости эффектов. Для ленты и экрана быстрой записи это терпимо. Мини-приложение «список заметок» собралось без проблем, список трудностей записан отдельно.
