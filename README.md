SecondBrain

Приложение для заметок, которое помнит людей, даты и договорённости за тебя. Пишешь как в мессенджере, остальное приложение раскладывает само.

Статус

Проект учебный. Сейчас этап проектирования. В репозитории стартовая страница из шаблона и документы: решения и схема архитектуры в папке docs. Первая версия покажет быструю запись без интернета: открыл, написал, сохранил.

Что будет в приложении

Быстрая запись. Работает без интернета, запись сохраняется на устройстве.

Время с разной точностью. Фразы вроде "весной" или "в конце месяца" хранятся так же полноценно, как точная дата.

Лента и досье. Все записи идут по порядку, а у каждого человека и места есть своя карточка с историей.

Дополнение записи. Вспомнил деталь через неделю, дописал её к старой записи.

Синхронизация через твой Google Диск. Данные шифруются на устройстве, Диск видит только шифр. Ключ есть только у тебя.

Помощник. Подключается по твоему собственному API-ключу и остаётся необязательным.

Установка на телефон как приложение, позже сборка APK для Android.

Технологии

React, TypeScript и Vite. Данные лежат в браузере (IndexedDB), приложение работает как PWA. Android-версию соберём через Capacitor.

Как запустить

Нужен Node.js. В папке проекта выполнить npm install, затем npm run dev. Страница откроется по адресу, который покажет команда. Сейчас это только стартовая страница из шаблона.
